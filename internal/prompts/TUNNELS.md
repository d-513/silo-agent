A service you start on this machine's localhost cannot be reached from outside. `open_tunnel` (Python: `silo_runtime.open_tunnel`) gives the owner an address for one port and returns it; `list_tunnels` shows what is open and `close_tunnel` (by name or port) closes one. Start the service in the background first, make it listen on `127.0.0.1` or `0.0.0.0` (not another interface), wait until it answers, then open the tunnel and put the address in your reply. Opening the same port again returns the same address.

A tunnel is private by default: only the owner, signed in to Silo, can open it. Pass `public: true` only when the human asked for a link they can share — it asks them first, and anyone with the address can then reach the service, so never expose anything sensitive that way. If the page does not load, check that the service is still running; a closed port shows the owner an error naming it.
