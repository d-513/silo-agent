This is the console that ships, built from the same source. Its server is replaced by a script that runs in this page, so nothing leaves your browser and nothing is behind it: no model, no machine, no network.

## Things to try

- **Answer a slip.** Open **Ledger** in the sidebar. It is paused on *Send an email*, which its rules set to Ask. Allow it or deny it, and read the receipt it leaves in the thread.
- **Send a message.** Type anything to **Atlas**. Four prompts play a recording of real work; they are on its Dashboard under *Try asking*. Anything else gets an honest answer that this is a demo.
- **Split a job.** Ask Atlas to *plan the spring catalogue launch with a team of subagents* and watch the taskboard above the thread and the tray below it.
- **Look around.** The Dashboard, Feed, Memories, Automations, Files and Rules pages are all filled in. The Desktop and Console need a live machine, so here they only say what they are.

What you change stays in this page's memory. **Start over** above the frame resets it.
